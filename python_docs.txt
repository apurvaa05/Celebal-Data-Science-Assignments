Common Exceptions

KeyError

Raised when a dictionary key or dataframe column does not exist.

NameError

Raised when a variable is not defined.

TypeError

Raised when an operation uses incompatible data types.

ValueError

Raised when an argument has the correct type but invalid value.

Python Best Practices

Use meaningful variable names.

Avoid unnecessary imports.

Return values instead of printing.

Write clean readable code.

Do not modify the original dataframe unless required.

Always access dataframe columns exactly as they appear.
