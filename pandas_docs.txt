PANDAS DOCUMENTATION

DataFrame

A DataFrame is a two-dimensional labeled data structure with columns of potentially different types.

Common Operations

df.head()
Returns the first 5 rows.

df.tail()
Returns the last 5 rows.

df.describe()
Returns descriptive statistics.

df.info()
Returns information about the dataframe.

df.columns
Returns all column names.

df.shape
Returns the number of rows and columns.

Selecting Columns

df["Salary"]

Selects the Salary column.

Selecting Multiple Columns

df[["Name","Salary"]]

Filtering

df[df["Salary"] > 50000]

Sorting

df.sort_values("Salary")

Descending Sort

df.sort_values("Salary", ascending=False)

Top Records

df.nlargest(5,"Salary")

Bottom Records

df.nsmallest(5,"Salary")

Unique Values

df["Department"].unique()

Value Counts

df["Department"].value_counts()

Mean

df["Salary"].mean()

Median

df["Salary"].median()

Maximum

df["Salary"].max()

Minimum

df["Salary"].min()

Sum

df["Salary"].sum()

Count

df["Salary"].count()

Grouping

df.groupby("Department")["Salary"].mean()

Group By Multiple Columns

df.groupby(["Department","Gender"])["Salary"].mean()

Aggregation

df.groupby("Department").agg({
    "Salary":"mean",
    "Age":"max"
})

Pivot Table

df.pivot_table(
    values="Salary",
    index="Department",
    aggfunc="mean"
)

Merge

pd.merge(df1,df2,on="EmployeeID")

Join

df1.join(df2)

Missing Values

df.isnull()

Count Missing Values

df.isnull().sum()

Drop Missing Values

df.dropna()

Fill Missing Values

df.fillna(0)

Rename Columns

df.rename(columns={
    "salary":"Salary"
})

Drop Columns

df.drop(columns=["Age"])

Drop Rows

df.drop(index=0)

Reset Index

df.reset_index()

Duplicate Rows

df.duplicated()

Drop Duplicates

df.drop_duplicates()

KeyError

A KeyError usually occurs when the specified column does not exist.

Always verify column names using:

df.columns

Common Fix

If code uses

df["salary"]

and the dataframe contains

Salary

replace

salary

with

Salary.
